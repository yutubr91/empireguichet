# 👑 EmpireGuichet

**La plateforme tout-en-un pour les agents de mobile money en Afrique de l'Ouest**

## 🎯 À propos

EmpireGuichet est une Progressive Web App (PWA) qui révolutionne la gestion des guichets de mobile money. Elle permet aux agents de centraliser toutes leurs opérations (MTN, Orange, Moov, Wave, Djamo, Crypto) sur une seule interface.

## 🚀 Installation

```bash
# Cloner le dépôt
git clone https://github.com/VOTRE_USERNAME/empireguichet.git
cd empireguichet

# Installer les dépendances
npm install

# Copier le fichier d'environnement
cp .env.example .env

# Lancer en développement
npm run dev
